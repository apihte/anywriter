# AW 图片 Caption 生成

对指定文件夹内的图片逐张反推 caption，并写入图片旁的同名 `.txt`。

## 共享参考

路径相对于本 Skill 目录：

- 规则：`../../../../shared/rules.md`
- 产物契约：`../../../../shared/artifact-contracts.md`

## 输入

- 图片文件夹路径（项目相对或绝对）。
- `.aw/config.json` 的 `caption_prompt`，作为本次任务的追加系统提示词。
- 可选：`-r`（覆盖已存在的 `.txt`，不传时跳过）、语言、格式、字段、递归子目录、文件过滤等补充要求。

## 流程

1. 读取 `.aw/config.json`；把 `caption_prompt` 作为追加系统提示词，它优先于 `writer_prompt`，并与用户本次的补充要求合并。缺少配置文件时使用默认 caption 规则。
2. 解析文件夹路径；缺少路径时先询问用户。默认只处理该目录下的图片，用户明确要求时递归子目录。支持的扩展名：`.png`、`.jpg`、`.jpeg`、`.webp`、`.gif`、`.avif`。
3. 按文件名排序逐张处理：
   - 使用 Read 工具查看图片；
   - `caption_prompt` 为空时使用默认规则：一段简洁的自然语言描述，覆盖主体、场景、构图、光线、色彩、氛围和风格；
   - `caption_prompt` 给出格式或字段时严格遵守；
   - 只描述可见内容，不编造不可见细节；不把水印、商标或画面文字写进 caption，除非 `caption_prompt` 明确要求。
4. 将 caption 写入图片旁的同名 `.txt`（UTF-8，按 `caption_prompt` 指定的格式；未指定时为单行文本）。
5. 参数中出现 `-r` 时覆盖已存在的 `.txt`；没有 `-r` 时跳过已存在的 `.txt` 并计入跳过数量。`-r` 从补充要求中移除，不作为 caption 指令。
6. 处理完成后报告成功数量、跳过文件和失败原因，给出抽样示例，并询问是否调整 `caption_prompt` 后重跑。

## 边界

- 图片只读：不修改、不重命名、不移动、不删除图片。
- 涉及裸露、性、暴力或其他敏感内容的图片，只输出中性、非露骨 caption；涉及未成年人的性化内容一律拒绝。
- 不复制水印、商标或受版权保护作品的具体标识和措辞。

## 完成标准

- 每张处理的图片都有对应 `.txt`，或明确报告跳过原因（已有文件且未传 `-r`）。
- caption 遵循 `caption_prompt` 或默认规则，且只描述可见内容。
- 只有传入 `-r` 时才覆盖已有文件。
