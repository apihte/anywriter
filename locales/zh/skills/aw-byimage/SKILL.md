# AW 图片参考生成

以用户上传的图片为不可变参考，先建立带区域证据的视觉参考表，经用户批准后再按需求生成内容。

## 共享参考

路径相对于本 Skill 目录：

- 规则：`../../../../shared/rules.md`
- 生命周期：`../../../../shared/lifecycle.md`
- 产物契约：`../../../../shared/artifact-contracts.md`
- 参考状态 Schema：`../../../../shared/image-reference-status.schema.json`
- 参考表模板：`../../../../shared/templates/image-reference.md`

## 输入

- 用户上传的图片。使用 `aw_save_images` 工具把会话中的上传图片保存到 `files/reference/<slug>/`，并采用工具返回的路径、字节数和 SHA-256；工具不可用时，才请用户提供图片的本地路径。不要凭对话附件重建文件。
- 生成要求：输出类型（正文 | 人物或场景设定 | 任务简报素材）、目标范围、风格模式和生成粒度。
- 可选：要接入的现有任务 ID 和已批准知识版本。

## 分支 A：图片参考提取

1. 读取共享规则、生命周期和产物契约。
2. 为本次参考创建唯一 `files/reference/<slug>/`；目录已存在时不覆盖，改用新 slug。
3. 调用 `aw_save_images`（传入目标 slug）把上传图片保存到该目录，并把返回的路径、字节数和 SHA-256 写入 `status.json` 的 `images`；找不到可保存图片时，请用户重新上传或提供本地路径。
4. 按 `shared/templates/image-reference.md` 逐张分析，只记录可观察的视觉事实：
   - 主体、外观、姿态、服装
   - 场景、环境、道具
   - 构图、景别、机位、视角
   - 光线、色彩、影调
   - 氛围和抽象风格特征
   - 画面内文字和水印
   - 不确定或不可见内容
5. 每条断言使用 `[reference:<slug>/<文件名>#<区域>]` 引用；区域使用 `center`、`top-left`、`background`、`foreground` 等描述。不得编造不可见细节。
6. 保存参考表为 `files/reference/<slug>/image-ref-v1.md`。
7. 将 `status.json` 状态设为 `pending_approval`，展示参考表、不确定项和拟用范围，停止等待用户批准。
8. 用户批准后写入批准记录并将状态设为 `approved`；用户要求修改时创建 `image-ref-v2.md` 并重新走门禁。

## 分支 B：按图生成内容

1. 确认参考表已批准且原图指纹未变化；否则停止。
2. 确定输出落点：
   - 接入现有任务：把参考表路径写入任务简报素材，并作为 aw-write 上下文包中的场景或风格参考；正文仍写入该任务的 `drafts/`，遵守任务状态门禁。
   - 独立生成：在 `files/reference/<slug>/drafts/` 写入版本化草稿，明确标记为非正典；需要进入创作流程时，引导用户改用 `/aw-task` 建立任务。
3. 生成时只使用参考表中已批准的可见特征；抽象迁移风格，不照搬画面文字、水印或受版权保护作品的具体表达。
4. 新引入的设定事实写入独立的 `drafts/<名称>-vN-facts.md`，保持草稿状态。
5. 更新 `status.json`：活动参考版本、草稿路径、`linked_task` 和下一步。
6. 展示要求覆盖清单（图片特征 → 文本落点），询问继续、修订或接入任务。

## 边界

- 图片仅作创作参考；不得用于伪造可识别真人的言行、冒充或诽谤。
- 涉及裸露、性、暴力或其他敏感内容的图片，只输出中性、非露骨的描述，不生成露骨内容；涉及未成年人的性化内容一律拒绝。
- 不复制图片中的水印、商标或受版权保护作品的具体标识和措辞。
- 不确定或不可见的细节必须标记，不得补造。

## 完成标准

- 原图不可变，且记录字节数和 SHA-256。
- 参考表每条断言都有区域引用，未批准前不生成内容。
- 生成内容只使用已批准参考和已批准知识，独立草稿明确标记为非正典。
- `status.json` 符合共享 Schema，并记录下一审批门或最终产物。
