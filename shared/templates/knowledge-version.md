# Knowledge Version Template

A knowledge candidate under `files/knowledge/versions/vN/` contains separate files for source coverage, story bible, characters, world, timeline, plot, style profile, and open questions. Use `distillation-character.md`, `distillation-world.md`, `distillation-plot.md`, and `distillation-style.md` as field-level templates during analysis.

Every material claim uses one of:

- `[files/source/<file>:Lstart-Lend]` for source evidence.
- `[files/work/<task>/final/<file>#heading]` for approved creative additions.

Each claim is marked as `fact`, `interpretation`, `uncertain`, or `conflict`. Empty dimensions are explicitly marked not applicable.
